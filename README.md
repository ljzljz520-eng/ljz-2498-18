# Catalpa 文稿台 · 编辑/预览位置同步

基于 `Vue 3 + Vite` 的 Catalpa 文稿编辑器，左右分栏（编辑区 / 预览区），
实现了**区间映射 + 稳定锚点**的位置同步体系，替代传统“两个容器按滚动百分比硬同步”的方案。

## 能力一览

- 编辑区与预览区可**锁定双向跟随**，也可**解锁各自滚动**；解锁保留双方当前位置，重新锁定以编辑区为准对齐
- 渲染后端返回**布局节点 → 源节点**的映射：一个源表格可**跨多页拆片**，一个预览段落可由**多个源行/源节点**组成
- 以**源行坐标 s 为中间语言**的分段线性映射，锚点之间局部插值，不做容器百分比硬同步
- 数据库（localStorage 适配层）保存**布局版本**与**个人阅读位置**（像素 + 源行锚点 + 分片签名）
- **代码折叠、图片懒加载成功/失败、字体替换、窗口缩放、DOM 更新**后自动重定位
- **实时浏览器测量 × 服务端布局索引**混合建模，多分片按服务端高度比例切分实测块；残差有限轮校正并收敛
- 映射不可用（请求失败且无缓存）时**自动降级为比例同步**，状态栏提示
- 双向滚动事件携带**发起端 token**，程序滚动回声在捕获阶段被标记并抑制，配合看门狗**杜绝反馈环/无穷跳动**
- 映射**回包乱序**按请求序号裁决丢弃；切稿以 `docId + 内容签名` 双守卫落库，**绝不串稿**
- 旧书签在布局版本变化后按**分片签名 / 序数 / 源行比例**三级迁移恢复

## 核心数据流

1. 编辑区：textarea 本身不暴露每行位置，由同规格隐藏 mirror div 逐行实测 → 行锚点
2. 预览区：`.src-block[data-block-id]` 实测 top/height；表格块结合后端多个分片，
   按 `分片高度 / 分片总高度` 切分实测块，得到跨页子锚点
3. 两侧锚点统一建到**源行坐标 s**，引擎在锁定时取发起端“视口焦点行”（距顶 24%），
   映射到对侧焦点应在的 y，再换算 scrollTop
4. 程序滚动带一次性 token；scroll 事件在 `scrollTop` 赋值时同步派发，
   捕获阶段把 pending token 贴到事件，bubble 阶段引擎识别为回声直接抑制
5. 程序滚动后 rAF 内复核源行残差，最多 2 轮收敛校正；
   1 秒内程序滚动超阈值触发看门狗熔断，防止任何意外反馈环造成无穷跳动

## 覆盖的测试场景（`pnpm test`，node:test）

- 长表拆页：60 行表格 → 多个布局分片、页码递增、全部指回同一源表格节点
- 多源节点段落：一个预览宽锚点；跨容器往返源行误差 < 0.6 行，拆片区 y 单调不回跳
- 代码折叠 / 图片加载 / 窗口缩放：几何换底后按最后焦点源行重定位；解锁时两侧各自保留
- 懒加载失败：`error` 事件同样触发重定位；映射失败注入后使用已保存布局或比例降级
- 映射回包乱序：旧 reqId 晚到判 `stale`；`invalidate` 作废在途请求；失败自动重试一次
- 恢复旧书签：同版本直取像素；签名命中迁移；签名失效按源行比例迁移，不丢位置
- 防反馈环：回声抑制、有限轮校正、振荡看门狗熔断
- 防串稿：切稿前冲刷旧稿位置；已切走/签名不符的迟到写入被拒绝；多文稿缓存隔离

## 调试控件（页面底部）

- 排版服务模式：`正常` / `乱序回包`
- `注入一次映射失败`：验证已保存布局回退与比例降级
- 状态栏实时显示当前模式（映射同步 / 比例降级）、请求/丢弃/失败计数
